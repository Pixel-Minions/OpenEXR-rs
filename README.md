# OpenEXR-rs

An exact Rust port of [OpenEXR](https://github.com/AcademySoftwareFoundation/openexr) **3.5.3**,
beginning with OpenEXRCore, accepted only on byte-by-byte parity with the official build.

Status: analysis and local harness; nothing is ported yet.

- `PLAN.md`: the plan, and the decisions awaiting the owner (§14).
- `CLAUDE.md`: the rules agents port by.
- `docs/baseline.md`: upstream's own tests and the oracle, as measured on the reference platforms.
- `upstream-map.toml`: every upstream file in scope and its status.
